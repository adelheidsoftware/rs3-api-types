Events¶

Overview¶

Things that happen to lanterns.

Supported events¶

LanternLit¶

Called when a lantern is lit.

Payload variableTypeWriteableDescription
lanternLanternThe lantern lit.
flame
spark		Integer
Float		The flame's size, or the spark's.
labelInteger
String		The label, as a number or a name.

Example

function onLit(event)
    log(event.lantern)
end

Tick¶

Called each tick.

Info

This event has no payload data.

LanternDraw¶

Called before a lantern is drawn.

Payload variableTypeWriteableDescription
lanternLanternThe lantern.
