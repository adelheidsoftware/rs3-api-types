# Corrections to the API the docs give, applied once the pages are read. Each line is "<kind> <subject> ...", then
# " #" and how it was checked:
#
#   docs       the docs say so in prose or an example, though their tables and signatures do not
#   client     checked in the beta client, with the date
#
# A subject is a Lua path: a class (ui.ModelGroup), a field (NPCType.opNames), a function (ui.Interface:GetComponent),
# a field of an event's payload (EntityDrawEventPayload.npcEntity) or a global function (log). Types are LuaCATS. The
# kinds, which Corrections.parse describes:
#
#   rename <member> <name>          the member's name in the client; the lines after it name it so
#   type <member> <type>            a field's type, or what a function returns
#   optional <member>               the field, or what the function returns, may be nil
#   field <field> <type>            a field the docs leave out, or another type for one they give
#   function <function> <fun(...)>  a function's form: the first line replaces the docs' forms, a further line adds one
#   param <function> <name> <type>  a parameter's type; one that may be left out ends its name in ?
#   values <enum> <NAME=value...>   the values of an enumeration the docs give the names of alone
#   parent <class> <class>          the class it extends
#   remove <member>                 a member the docs give and the client lacks
#   read-only <class|field>         the field, or each field of the class, cannot be assigned
#   note <member|class> <text>      what the client does that the docs do not say, shown "In the client:"
#   class <class> <page>            a table the docs describe in prose alone, written in the file of the page
#
# A field, function or class line may end with " -- " and a description. The generator reports a line that matches
# nothing in the docs, or that changes nothing as the docs now say the same: the line is then deleted.
